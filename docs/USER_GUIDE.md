# 運用ガイド

1. 運営管理画面を開き、管理者が許可した Google アカウントでログインします。共有された大会 ID を入力して「接続」を押します。
2. 「全タスク」で作業を登録します。担当タスクの進捗は運営メンバーが更新できます。完了を選ぶと進捗は100%です。アーカイブしたタスクは同じ画面の状態フィルターから復元できます。
3. 「大会ステージ」で開催日・確度と準備項目を確認します。開催日が未定の場合は空欄のまま保存します。
4. 「未確定・決定事項」で判断内容を記録します。決定すると、同時に決定ログが記録されます。
5. 週の節目に「週次レビュー」のスナップショットを保存します。比較元と比較先を選んで差分を確認し、会議用に Markdown をコピーできます。
6. 「情報公開」で参加者向けに書き直した本文を登録します。「参加者向け表示をプレビュー」で内容を確認し、情報の確度を確定にした上で承認します。解禁後に管理者が「公開」を押します。公開内容を変更する場合は「公開取消」、編集、再承認、公開の順です。
7. 「運営メンバー」で、本人が Google ログインを済ませたアカウントの Firebase UID を登録します。運営メンバーは担当タスクのみ編集でき、閲覧専用は参照のみです。新規ログインだけでは権限は付与されません。
8. 「バックアップ」で対象を選び、非公開の保管先へ JSON を書き出します。復元は、同じ大会 ID のバックアップを選び、対象と重複件数を確認して実行します。既存 ID はスキップします。対象外のデータは画面で確認してください。

管理者が公開した情報は参加者向けページに表示されます。内部用の URL、個人情報、未承認情報は公開原稿に含めないでください。


## 作業期間とガントチャート

- 「全タスク」で対象を選び、「作業予定」に開始予定日と終了予定日を入力して保存します。約束した締切は「期限」に入力します。
- 「大会ステージ」で「準備開始日」「準備終了予定日」を入力します。試合の日付は「開催日」に入力します。
- サイドバーの「ガントチャート」で双方を確認できます。青緑の帯は開始から終了まで、丸は開始または終了だけ、ひし形は締切または開催日です。未定の日付は空欄のまま保存できます。スマートフォンでは表を横にスクロールできます。
- 予定日の変更は項目名を押して編集画面を開きます。
